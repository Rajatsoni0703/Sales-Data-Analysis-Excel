# Sales Data Analysis Dashboard (Excel)

## 📊 Project Overview
This project involves analyzing sales data using Microsoft Excel and creating an interactive dashboard.

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Charts, Slicers)

## 📈 Key Insights
- Identified top-performing product categories
- Analyzed regional sales and profit trends
- Tracked monthly sales performance

## 📌 Features
- Interactive dashboard with slicers
- Visual charts for better understanding
- KPI metrics (Sales, Profit, Orders)

## 📂 Files Included
- Excel Dashboard File
- Dataset
